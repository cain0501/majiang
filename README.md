# 聚会/活动报名

13 个人的群报名 + 房间管理。一个 Cloudflare Worker 同时干三件事：发页面、给接口、存数据。
**不用买服务器，不用备案，0 元。**

## 核心设计：身份先建好，报名只能选自己

不是让人手打名字——那样一定会出现「老王 / 王哥 / 老王头」三个张三，排行榜直接废掉。

改成：

1. **群主先把 13 个人建进名单**，每人一个名字 + 一个头像
2. 群友打开链接，**从名单里点自己**（不是打字）
3. 身份记在手机本地，以后再打开自动认得
4. 报名、记分、排行全部按**成员 id** 走，改名字也不会串数据

头像是「名字首字 + 自动配色」，也可以从 27 个表情里挑一个。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `core.js` | **唯一的规则源**：报名、分配房间、计分、名单。前端和云端共用 |
| `app.template.html` | 页面源码（改界面改这个，别改 index.html） |
| `worker.template.js` | Worker 模板，`__PAGE__` 会被替换成页面 |
| `build.mjs` | 把 core 内联进页面 → 生成 `index.html`，再把页面塞进 Worker → 生成 `worker.js` |
| `index.html` | 构建产物，改了会被覆盖 |
| `worker.js` | 构建产物，部署的就是它 |
| `wrangler.toml` | 部署配置，需要填 KV 命名空间 id |
| `_devserver.mjs` | 本地跑真 Worker，用内存 Map 顶替 KV |
| `test.mjs` / `test-cloud.mjs` | 单机测试 / 多端同步测试 |

改完 `app.template.html` 或 `core.js`，跑一次 `node build.mjs`。

## 本地先看效果

```bash
npm install
node build.mjs
node _devserver.mjs
```

打开 http://127.0.0.1:8788 ，手机模式（F12 → 切设备）看着最像。

想模拟「两部手机」：开两个无痕窗口，都访问这个地址，各自选一个身份。

## 部署（约 5 分钟，一次性）

```bash
npx wrangler login                       # 弹浏览器，注册/登录 Cloudflare（免费）
npx wrangler kv namespace create MJ_KV   # 建存储，输出一个 id
# 把那个 id 填进 wrangler.toml
node build.mjs
npx wrangler deploy
```

跑完会打印 `https://majiang.你的子域.workers.dev`，**这个就是发群里的链接**。

以后更新：`node build.mjs && npx wrangler deploy`。

## 群友怎么用

1. 群主把链接发群里，自己先建好 13 人名单（⚙ → 成员管理）
2. 群友点链接 → 选自己 → 在目标房间卡片点「报名此房间」

不用下载、不用关注、不用注册。所有人看到同一份名单，5 秒内自动刷新。

## 房间和历史

这两个词别混：

| 词 | 意思 | 谁决定 |
| --- | --- | --- |
| **房间** | 一间实际打麻将的地点 | 每个房间独立设置房号、标题、地点、开始时间和时长 |
| **历史** | 已经结束的房间 | 时间结束后自动归档，只在「历史」里保留 |

所以「今晚要开两间房」就在页面下方点两次「＋ 添加房间」，再分别编辑房间信息。

每个房间最多 4 人，超出已开放房间容量的人自动进入候补：

- 开 1 个房间：4 人入场
- 开 2 个房间：8 人入场
- 开 3 个房间：12 人入场

每个房间到达「开始时间 + 开打时长」后自动结束并归档，不会继续出现在报名列表里。

## 规则

- 开始时间到了仍未满 4 人的房间自动取消，不计入历史；已经开打的房间结束后会先提示记录本局分数
- 按报名先后排队，分配到已开放且有空位的房间
- 房间显示「2/4 · 还差 2 人」，用户可换到有空位的房间
- 每个房间在自己的开打前 N 小时自动截止报名，最后一小时倒计时变红
- 截止后退出扣 10 点信用分，**开台之后也照样能退**（记一次放鸽子，同样 -10）
- 报名会截止，但退出永远点得动——人临时来不了是常事，不能把人卡在房间里
- 超过房间容量的进候补，有人退自动顶上
- ⚙ 里可以改每个房间的房号 / 标题 / 时间 / 地点 / 开打时长 / 提前几小时截止，也能记分
- 成员名单随时能改，改名不影响历史战绩

## 记分怎么记

**一个房间一条记录。** ⚙ →「房间记分」，会按房间列出：

```
房间 1  老王、阿强、小陈、李姐     合计 0   [改] [删]
房间 2  周哥、胖子               未录      [录入]
```

点进去填每人的输赢分（赢为正、输为负，比如 `+120 / -40`）：

- 底下**实时显示合计**，正好 0 就绿色，不归零就变红
- 不归零时按钮会变成「合计 +30，仍然保存」，不拦你，但提醒你
- 同一房间重新录是**覆盖**，不会累加；录错了可以「删」

排行的算法：

| 字段 | 含义 |
| --- | --- |
| 总分 | 所有局分数累加 |
| 局数 | 有效成绩的局数 |
| 胜率 | 分数 > 0 的局数 ÷ 总局数（0 分算没赢） |
| 信用 | 100 起，截止后退出 -10，**存在成员身上，跨局累计** |

## 注意

- 标题和域名里别出现「麻将」「棋牌」「赌」这类词，微信对这类关键词有风控，容易被拦。页面写「周五聚会报名」更稳妥。
- 免费额度：每天 10 万次请求，你这个群一年也用不完 1%。
- 如果以后觉得 `workers.dev` 慢，绑一个自己的域名走 Cloudflare CDN 会明显快。
